# 🛍️ Интернет-магазин на Django

Полноценный интернет-магазин с корзиной, оформлением заказов, промокодами, выбором цвета, рассрочкой и оплатой картой.

## 🚀 Функционал

- ✅ Категории товаров с иконками
- ✅ Товары с картинками, ценой, описанием
- ✅ Выбор цвета для каждого товара
- ✅ Корзина (добавление, удаление, изменение количества)
- ✅ Промокоды (активация и пересчёт суммы)
- ✅ Оформление заказа
- ✅ Выбор способа оплаты:
  - 💳 Картой онлайн
  - 📱 Рассрочка (3, 6, 12, 24 месяца)
  - 📦 При получении
- ✅ Поиск товаров
- ✅ Хиты продаж и новинки на главной
- ✅ Красивый адаптивный дизайн
